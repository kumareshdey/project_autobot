# HeroChat: Spiderman & Batman AI Banter

## Overview

**HeroChat** is a playful chat application built with Streamlit, Langchain, and Ollama's language models. Chat with two iconic characters—Spiderman and Batman—each powered by a humorous conversational AI. This project is a lighthearted exploration of large language models and their ability to mimic personalities.

> **Note:** This project was created for fun and experimentation. Please don't judge the code quality too harshly!

## Features

- Chat with Spiderman and Batman, each with their own witty AI persona
- Powered by Langchain and Ollama's llama3.1 model
- Simple Streamlit interface for easy interaction

## Setup

1. **Install Ollama**  
   For Linux:  
   ```bash
   sudo snap install ollama
   ```

2. **Pull the Ollama 3.1 Model**  
   ```bash
   ollama pull llama3.1:8b
   ```

3. **Install Python Requirements**  
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the Streamlit App**  
   ```bash
   streamlit run application.py
   ```

## Usage

Open your browser to the Streamlit URL provided in the terminal and start chatting with your favorite superhero!
